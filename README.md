## Teste Econverse: Vaga Desenvolvedor Front-End ##
Este projeto foi criado utilizando o Vite, React, TypeScript e Sass.

### Pré-Requisitos
Antes de começar, certifique-se de ter instalado em sua máquina:
- Node.js (versão 14 ou superior)
- npm ou yarn

### Clonar o repositório
Clone este repositório em sua máquina local usando o seguinte comando:
```bash
git clone [https://github.com/thiago0-08/Teste-Econverse](https://github.com/thiago0-08/Teste-Econverse)

Navegue até o diretório do projeto:

cd Teste-Econverse

Instale as dependências do projeto usando o npm ou yarn:

npm install
ou
yarn


Rodar em Ambiente de Desenvolvimento
Para iniciar o servidor de desenvolvimento, execute:

npm run dev
ou
yarn dev
